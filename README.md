# LMS Video Auto Next——可用于中山大学在线教学平台

一个用于 LMS 在线课程页面的 Tampermonkey 用户脚本。

这个脚本的目标是帮助用户在视频学习页面中减少重复操作，例如自动检测视频结束、跳转到下一学习项、在跳转后尝试继续播放，以及在章节测验页面出现时提醒用户手动处理。

请遵循学校的相关规定，
对于使用该脚本产生的一系列问题作者概不负责

本作者非计算机专业学生，所有代码均由codex生成，可能存在某些未知风险。

## 来源

本仓库基于 [Leisure-Player/SYSU_OnlineClass_GuoJiaAnQuanJiaoYu](https://github.com/Leisure-Player/SYSU_OnlineClass_GuoJiaAnQuanJiaoYu) 继续更新，主要增加课程结构兜底、章节末尾视频跳转和自动播放兜底。

## 功能

- 自动识别课程视频元素（包括页面内嵌的 `mod/page`、`mod/resource` 等视频）
- 视频播放结束后自动跳转到下一项
- 页面没有“下一节”按钮时，自动从课程索引、导航块或课程主页解析下一项
- 识别隐藏在页面里的“下一节”链接，并用更多关键词兜底
- 跳转到下一视频页后自动尝试继续播放
- 视频异常暂停时自动尝试恢复播放
- 支持 `dryRun` 模式，便于先测试再正式启用
- 提供右下角调试面板，可查看当前识别状态与“下一项”的来源
- 支持收起/展开调试面板，避免遮挡页面按钮
- 进入章节测验页面时弹窗并发出声音提醒用户手动完成
- 记录运行日志，便于排查问题

## 不包含的功能

- 不包含自动答题
- 不包含自动选择题目选项
- 不包含自动提交测验或考试
- 不包含账号、Cookie、Token 等敏感信息管理

## 适用页面

当前脚本主要面向以下页面：

- 视频资源页：`/mod/fsresource/view.php`
- 其他可能含视频的活动页：`/mod/page/view.php`、`/mod/resource/view.php`、`/mod/url/view.php`、`/mod/scorm/view.php` 等
- 讨论列表页 / 讨论详情页：`/mod/forum/view.php`、`/mod/forum/discuss.php`
- 测验说明页：`/mod/quiz/view.php`
- 测验作答页：`/mod/quiz/attempt.php`
- 测验提交页：`/mod/quiz/summary.php`

## 安装方式

### 1. 安装 Tampermonkey

先在浏览器中安装 Tampermonkey 扩展。

- Chrome / Edge：在扩展商店搜索 `Tampermonkey`
- Firefox：在附加组件商店搜索 `Tampermonkey`

### 2. 导入脚本

1. 打开 Tampermonkey 面板
2. 将 `tampermonkey-lms-autonext.user.js` 文件拖入Tampermonkey页面
3. 点击安装脚本
4. 1.2.1 起脚本会申请 `GM_xmlhttpRequest` 与 `lms.sysu.edu.cn` 连接权限，用于携带登录态读取课程主页，请点击允许
5. 打开中山大学在线教学平台，并刷新页面

## 使用说明

### 基本流程

1. 打开课程视频页面
2. 确认右下角出现脚本面板
3. 先保持 `dryRun: ON`，测试识别与日志是否正常
4. 确认无误后切换到 `dryRun: OFF`
5. 视频结束后，脚本会自动跳到下一项
6. 如果下一项仍是视频，脚本会尝试继续播放
7. 如果进入测验页，脚本会提醒用户手动完成

### 调试面板

面板提供以下能力：

- 重新扫描页面元素
- 切换 `dryRun`
- 手动测试“下一节”跳转
- 导出日志
- 清空日志
- 从零重置脚本状态
- 收起 / 展开面板

### 下一项来源

面板里的“下一项来源”会显示脚本是如何找到下一项的：

- `selector:#next-activity-link`：页面自带“下一节”按钮
- `jump-select`：页面“跳至”下拉框
- `structure:...`：页面内的课程索引 / 导航块
- `course-scan`：自动读取课程主页并解析活动顺序
- `keyword-score`：按“下一节 / 下一个活动 / next”等关键词兜底

如果显示“未识别”，可以点击“重新扫描”或“测试下一节”，再导出日志排查。

### 已知限制

- 如果视频被放在跨域 `iframe` 中，浏览器安全策略不允许脚本访问其内容，脚本无法识别或控制该视频。
- 如果课程主页本身需要额外权限或被隐藏，`course-scan` 可能拿不到完整活动列表，此时会退回页面内的导航链接。
- 浏览器可能拦截自动播放。脚本会自动重试，失败后会显示“自动播放被浏览器拦截，点击继续播放”按钮，点一下即可。

## 更新说明

### 1.2.1

- 针对“章节最后一个视频没有下一节按钮”的页面：使用 `GM_xmlhttpRequest` 携带登录态读取课程主页，按活动顺序找到下一项（例如 2144927 后的 2144928）
- 自动播放被浏览器拦截且重试失败时，显示“自动播放被浏览器拦截，点击继续播放”按钮
- 课程主页请求优先使用 `GM_xmlhttpRequest`，失败时自动退回 `fetch`

### 1.2.0

- 新增课程结构解析兜底：页面没有“下一节”按钮时，仍可从课程索引、导航块或课程主页找到下一项
- 支持隐藏在页面里的下一节链接，并补充“下一项 / 下一个活动 / next activity”等关键词
- 支持 `mod/page`、`mod/resource` 等页面中的内嵌视频，以及同源 iframe 内的视频
- 修复面板刷新与 DOM 监听互相触发导致的反复重扫，避免自动续播/暂停恢复被反复打断
- 视频结束时即使拿不到 `duration`，也允许按原生 `ended` 事件跳转
- 自动跳转后如果 URL 带有额外参数（如 `lang`），仍能正确识别为同一活动并续播

## 运行边界

这个脚本只用于视频页面导航和人工提醒，不具备自动化答题能力。

如果平台规则、学校要求或课程规范不允许类似脚本，请不要使用。

使用者应自行确认：

- 是否符合所在平台的使用规定
- 是否符合课程要求
- 是否符合学校或组织的相关政策
